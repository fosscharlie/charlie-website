# Changelog

## Unreleased

- Added 16 new effects: orbit, pixelate, glitch, ascii, halftone, warp, swirl, spotlight, shatter, CRT, wave, cube, gravity, snow globe, trail and tunnel. There are now 24.
- Added six more effects: hologram, black hole, globe, matrix, liquid and neon. There are now 30.
- Added twenty more effects: synthwave, reflection, pop art, thermal, prism, fireworks, stained glass, bubbles, city, film, carousel, night vision, pixel sort, sliding puzzle, painter, flag, LED board, plasma ball, paper layers and mirror ball. There are now 50.
- Added a small "next" pill in the bottom right, the same size as the WhatsApp and Signal tag and in line with it. Its second part changes between "hover image" or "touch image" (on a phone or tablet) and "for effect". The tag moved to the bottom left.
- An effect can be chosen by ending the address with its number, for example `/#11`.
- The page now has a text description for screen readers, follows the reduced motion setting (movement stops after five seconds unless you touch or move the mouse), and changes effect when the number in the address is edited.
- Removed the hidden content credentials from the avatar image, in the page and in the repository.
- The WhatsApp and Signal tag and the Next pill now have a dark backing, so their text always has enough contrast.
- The picture now stops above the buttons on small screens, so nothing sits over it.
- Added the readme, security page, contributing page and changelog.
