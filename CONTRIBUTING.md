# Contributing

Thank you for taking an interest in this project.

This is a small personal site, and I look after it on my own. For that reason I do not merge code changes from other people. That is simply how the project is set up, and it is not a judgement on your work.

What helps most is a description. If you found a problem or have an idea, please [open an issue](https://github.com/fosscharlie/charlie-website/issues) and tell me:

- what you did,
- what you expected to happen,
- what happened instead,
- your browser, its version and your device.

If the problem is a security one, please do not post it in public. Follow [SECURITY.md](SECURITY.md) instead.

You are welcome to fork the project and change it as you like. The licence ([LICENSE](LICENSE)) allows it.
