# Security

## Supported versions

Only the page that is live at [charlie.cx](https://charlie.cx) and the latest version in this repository are supported.

## Reporting a problem

Please report security problems in private first.

Open an [issue](https://github.com/fosscharlie/charlie-website/issues) asking for a private way to get in touch. Leave out the details of the problem, and I will reply with where to send them.

## What to expect

This is a personal project looked after by one person. I will read a report as soon as I can and aim to reply within a week. I cannot promise a fix by a set date, but I will tell you what I decide and why.

## What the site does

The page is one HTML file with its script written inline. It has no forms, no accounts, no cookies and makes no requests to other sites, so the likely problems are few. It has no links to other sites.
